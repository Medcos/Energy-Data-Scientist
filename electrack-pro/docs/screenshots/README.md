# Screenshots

Ce dossier accueille les captures d'écran illustrant ElecTrack Pro en usage réel. À anonymiser systématiquement avant publication (flouter/remplacer tout email, nom de client, nom de localité réel).

Suggestions de captures à inclure, par ordre d'impact pour un portfolio :

1. **Vue d'ensemble du tableau de bord** — indicateurs d'avancement pondéré par localité (le résultat le plus parlant pour un client non technique)
2. **Formulaire de saisie terrain** (mobile) — montre l'expérience utilisateur réelle du superviseur sur le terrain
3. **Vue superviseur vs vue admin** — deux captures côte à côte illustrant la restriction de zone par rôle
4. **Table de classement / recap** (`Top_Localites`) — preuve visuelle du reporting automatisé
5. **Exemple d'email d'alerte** (inactivité ou anomalie) — reçu généré automatiquement, adresse/nom anonymisés
6. **Schéma d'architecture** (peut être un export du diagramme Mermaid de `architecture.md` si un rendu image est préféré à GitHub)

## Anonymisation avant ajout

- Aucun nom de client, de projet, ou de localité réelle visible
- Aucune adresse email réelle visible
- Remplacer par des données de démonstration si nécessaire (ex. "Client Démo", "Zone A", "Superviseur Test")
